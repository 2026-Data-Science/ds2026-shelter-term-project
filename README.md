# ds2026-shelter-term-project

**AI-Based Shelter Animal Adoption and Long-Term Shelter Risk Analysis**
Data Science (14455_001) — Term Project, Team #3

---

## 1. Problem Definition

Animal shelters operate under limited resources, which makes two analyses critical:
- Which animals are at high risk of long-term shelter stay
- Which characteristics influence the likelihood of adoption

This project applies machine learning to:
- Predict the final outcome of each animal (Adoption / Transfer / Return_to_owner / Euthanasia / Died)
- Cluster animals at risk of long-term shelter stay
- Derive operational insights that support shelter management and animal welfare

The goal is not to identify "easily adoptable animals" but to enable the early identification of vulnerable animals so that welfare and shelter operations can be improved.

---

## 2. Dataset

**Kaggle — Shelter Animal Outcomes** (Austin Animal Center, 2013-10 to 2016-02)
- 26,729 animal records
- Categorical: `AnimalType`, `Breed`, `Color`, `SexuponOutcome`, `OutcomeType`
- Numerical (derived): values engineered from `AgeuponOutcome` and `DateTime`
- Missing values: `Name` 28.77%, `OutcomeSubtype` 50.93% — handled in preprocessing
- Source: https://www.kaggle.com/competitions/shelter-animal-outcomes/data

The dataset satisfies every project requirement: more than 10 rows and columns, a mixture of numerical and categorical variables, a meaningful amount of dirty data, applicability of scaling and encoding, and full coverage of classification, clustering, and k-fold cross validation.

## 3. Planned End-to-End Process

| Stage | Description |
|-------|-------------|
| Data Preprocessing | Missing value handling, feature engineering, encoding, scaling |
| Modeling — Classification | Logistic Regression, Decision Tree (interpretable multi-class models) |
| Modeling — Clustering | K-Means for identifying long-term shelter risk groups and senior animal groups |
| Evaluation | Classification: k-fold cross validation with accuracy, precision, recall, F1; Clustering: visualisation and cluster interpretation |

## 7. Quick Start

```powershell
# 1) Install dependencies
pip install -r requirements.txt

# 2) Download train.csv from Kaggle and place it under data/
#    https://www.kaggle.com/competitions/shelter-animal-outcomes/data

# 3) Run the preprocessing pipeline end-to-end
python main.py
```

`main.py` loads `data/train.csv`, runs `fit_transform` through the preprocessing pipeline, prints a summary to stdout, and writes `outputs/preprocessing_report.md` so that the run can be reviewed without re-executing the script.
